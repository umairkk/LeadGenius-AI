# Umair Altaf Premium Brand Website

A modern Next.js 15 personal brand website for Umair Altaf, a Digital
Marketing Consultant and Performance Marketing Expert.

## Features

- Premium dark blue, white, and gold design system
- Fully responsive App Router architecture
- Home, About, Services, Case Studies, Portfolio, Certifications, Achievements,
  Testimonials, Booking, Blog, and Contact pages
- Data-driven services, case studies, portfolio, testimonials, FAQs, and blog
  posts
- Framer Motion animations, animated counters, charts, and filterable results
- Calendly-ready booking section and CRM-ready contact/consultation forms
- SEO metadata, article schema, person schema, and GTM readiness
- Tailwind CSS styling with performance-conscious static rendering

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to view the site.

## Production

```bash
npm run build
npm run start
```

Set `NEXT_PUBLIC_GTM_ID` to enable Google Tag Manager. Replace the placeholder
contact details, WhatsApp link, and Calendly URL in `app/data.ts` with live
business details before launch.
